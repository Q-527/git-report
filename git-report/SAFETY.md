# 安全说明（git-report）

git-report 是一个**只读 + 显式确认**的 Claude Code 插件。我们把"不伤人"作为一等约束：

## 它绝不自动做什么
- 不自动 `git push`、不创建/强制推送分支。
- 不自动 `git reset --hard`、不 `git checkout .`、不丢弃任何未提交改动。
- 不自动 `gh` / 调用任何会改动 GitHub 远端或创建 PR/Issue 的命令。
- 不联网、不调用任何 MCP 服务器、不上传你的代码或报告。

## 它只在你确认后才做什么
- **`/git-report:commit`**：先展示生成的提交信息，你确认后才会执行 `git commit`。
  - 它**不会**用 `git commit -a`（自动暂存全部），只提交你已经 `git add` 进暂存区的内容，避免误提交。
  - 它不会带 `--no-verify` 绕过你的 pre-commit 钩子。
  - 多条不相关的暂存改动，它会建议拆分，而不是硬塞进一条提交。
- **`/git-report:pr`**：只生成 PR 描述文本。要不要真的创建 PR，由你来决定并执行。

## 数据来源
所有报告、Changelog、提交信息、PR 描述**仅基于你本地仓库的真实 git 数据**。没有提交就不会编造，未暂存的改动不会被偷偷提交。

## 配置不会外泄
`.git-report.json` 只存在于你的仓库本地，插件不读取、不上传任何与配置无关的信息。

如你发现任意技能违反了上述约束，请提 Issue 反馈。
