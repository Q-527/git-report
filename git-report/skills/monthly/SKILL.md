帮用户生成"本月工作月报"。

范围：本月 1 号 00:00 到当前时刻。月初日期用 `date +%Y-%m-01` 取得。其余流程与 daily 一致（多仓库、--since/--until、聚合、中文分组、禁止编造、询问落盘）。

报告结构：
- 标题：工作月报（YYYY-MM）
- 概览：本月 N 个提交、M 个文件变更
- 本月亮点 / 里程碑（月报更看重"这个月完成了什么大的"）
- 按模块 / 功能分组的核心进展（通顺中文，不堆原文）
- 风险 / 遗留问题
- 下月计划（可选，简短）

只基于真实 git 数据，禁止编造。输出后询问是否写入 `报告-月-YYYY-MM.md`。
